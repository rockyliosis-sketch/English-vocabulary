### 为什么对未知线上数据安全

1. 以执行时的当前数组计算缺口，而不是用快照覆盖整列。`usable_count` 是过滤原场景后的条数，不使用“全被过滤后回退完整列表”的展示兜底来充数。`needed = 3 - usable_count`，已有至少 3 条的行不更新。
2. 候选先按同一规则归一化，排除当前库中**任何词**的例句及原场景占用的文本，包括本词已有句、大小写/空白/尾标点变体；候选之间也要求互不重复。候选按顺序选取，只追加所缺条数。每词另有两条后备候选，供未知线上内容撞句时使用。
3. SQLite 自带 `lower()` 只覆盖 ASCII，因此生成器从 JavaScript 的 Unicode 规则生成纯 SQL 比较表，包含空白、标点、大小写和希腊词尾 sigma；不依赖 D1 自定义函数。测试直接对照独立的运行时 `normalizeExampleText`，包含 NBSP、全角标点、重音字母、Kelvin 符号、İ 和 sigma 等情况。
4. 单条 UPDATE 使用物化的当前内容计划，且最终仍比较原 examples_json 和 original_context，保留旧值保护。只更新 examples_json，不改或新增词条及复习历史；重复执行不再追加。
5. 安全边界：若保留全部原项会使 `raw_count + needed > 5`，整行标为 `blocked_capacity` 并跳过。例如已有 5 项但只有 2 项不是原场景时，三项要求无法同时满足；本轮不会擅自删句。候选不足则标为 `blocked_candidates`，也不做部分填充。非法数组或不完整项跳过对应行；全库英句/场景若有 NUL 或超过 2000 字符的文本则暂停全部补句（`blocked_text`），避免不完整归一化检查。
6. 下限检查面向所有有效词条；本轮已审核的候选只针对快照中缺失列表的 scope/range。若线上其它词也不足 3 条，预览会显示其 `blocked_candidates`，须另备相关例句，不能给未知词塞入 scope/range 的句子。

只读预览方式已写在 `03` 文件头：**用该 SELECT 替换末尾整个 UPDATE，而不是把它们连着执行**。可查看所有有效行的原始数、可用数、缺口、可用候选数和状态。只保留规则与候选源时，可在本地运行 `node scripts/build-example-top-up-sql.mjs` 重新生成 stdout；生成结果仍须人工审核，不能据此自动执行。

### 相关词复核与修正清单

已逐项检查 39 组、117 项的 IPA、词性、中文与关系，改 9 项，其余 108 项保留。采用美式宽式 IPA，省略长音号，保留 r 或 ɝ；/ər/ 是带 r 的转写，不按英式不卷舌处理。未把有效的美式元音变体、清晰的强读短语或单音节词强行改写。词性检查没有发现需要改动的项目。

| 词条 → 相关词 | 修正 |
| --- | --- |
| variety → various | `衍生` 改 `同词族`，避免暗示直接由 variety 派生 |
| variety → diversity | `近义` 改 `相关`；当前 variety 的“品种”义不能直接等同“多样性” |
| range → wide-ranging | `衍生` 改 `复合词` |
| incredible → credible | 反义限定为 `反义（难以置信义）` |
| incredible → amazing | 近义限定为 `近义（极好义）` |
| separation → reunion | `/riˈunjən/` 改 `/ˌriˈjunjən/`，补 /j/ 与次重音；反义限定为“分离义” |
| practically → virtually | 中文收窄为 `几乎`，对应当前 practically 的近义用法 |
| ranking → top-ranked | `排名最高的` 改 `名列前茅的`；关系改 `复合词` |
| responsible → accountable | 中文改 `须负责的`，强调负有责任 |

核对依据：reunion 的美式重音与 /j/ 见 [Cambridge 发音](https://dictionary.cambridge.org/us/pronunciation/english/reunion)；incredible 的两个义项见 [Cambridge incredible](https://dictionary.cambridge.org/us/dictionary/english/incredible)；top-ranked 可以指同类中的佼佼者，见 [Cambridge top-ranked](https://dictionary.cambridge.org/dictionary/english/top-ranked)；accountable 的责任要求见 [Cambridge accountable](https://dictionary.cambridge.org/us/dictionary/learner-english/accountable)。词族/复合词标签与义项限制是结合当前词条作出的编辑判断。

保留项的核对示例：dutiful 原 `/ˈdutɪfəl/` 是可接受美式，见 [Cambridge dutiful](https://dictionary.cambridge.org/dictionary/english/dutiful)；irresponsibility 原转写符合 [Oxford 美式条目](https://www.oxfordlearnersdictionaries.com/us/definition/english/irresponsibility)，不把它误改为所谓统一发音。[Cambridge 音标说明](https://dictionary.cambridge.org/us/help/phonetics)也说明不同词典栏目在长音号等写法上存在差异。以上未复制词典例句到补句或测试。
